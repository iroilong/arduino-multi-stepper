# 接線紀錄

## 已確認硬體

- 控制板：Arduino Mega 2560 相容板
- 馬達：三顆 28BYJ-48 12V DC 步進馬達
- 驅動板：三片 ULN2003 驅動板

## 訊號線接法

同一份 pin 對接也寫在專案根目錄的 `motion_plan.h`。如果實際接線改變，請同步修改 `motion_plan.h` 的「使用者設定區 1：硬體接線」。


| 馬達 | ULN2003 IN1 | ULN2003 IN2 | ULN2003 IN3 | ULN2003 IN4 |
| --- | ---: | ---: | ---: | ---: |
| 馬達 1 | Mega D22 | Mega D24 | Mega D26 | Mega D28 |
| 馬達 2 | Mega D30 | Mega D32 | Mega D34 | Mega D36 |
| 馬達 3 | Mega D38 | Mega D40 | Mega D42 | Mega D44 |

## 馬達接法

- 每顆 28BYJ-48 馬達的白色接頭，插到自己的 ULN2003 驅動板白色座。
- 初次測試不要改馬達線序。

## 電源接法

- ULN2003 `+` 接外部 12V 電源 `+`。
- ULN2003 `-` 接外部 12V 電源 `-`。
- Arduino `GND` 接外部 12V 電源 `-`。
- 三片 ULN2003 的電源負極要共地。

## 狀態 LED

- Arduino Mega 2560 板上 `L` LED 接在 `PB7/D13`。
- 程式會讓這顆 LED 持續閃爍，表示 MCU 還在執行。
- 這顆 LED 不需要額外接線。

## 安全檢查

- Arduino USB 只負責上傳程式與控制訊號。
- 馬達電源由外部 12V 電源供應。
- 改接線前先拔掉馬達電源。
- 先只接馬達 1，測試成功後再接馬達 2 和馬達 3。
- 目前 IN1-IN4 都安排在 Mega 2560 右側長排 header 的同一側偶數腳位，方便排線整齊插接。
