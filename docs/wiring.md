# 接線紀錄

## 已確認硬體

- 控制板：Arduino Mega 2560 相容板
- 馬達：三顆 28BYJ-48 12V DC 步進馬達
- 驅動板：三片 ULN2003 驅動板

## 訊號線接法

| 馬達 | ULN2003 IN1 | ULN2003 IN2 | ULN2003 IN3 | ULN2003 IN4 |
| --- | ---: | ---: | ---: | ---: |
| 馬達 1 | Mega D22 | Mega D23 | Mega D24 | Mega D25 |
| 馬達 2 | Mega D26 | Mega D27 | Mega D28 | Mega D29 |
| 馬達 3 | Mega D30 | Mega D31 | Mega D32 | Mega D33 |

## 馬達接法

- 每顆 28BYJ-48 馬達的白色接頭，插到自己的 ULN2003 驅動板白色座。
- 初次測試不要改馬達線序。

## 電源接法

- ULN2003 `+` 接外部 12V 電源 `+`。
- ULN2003 `-` 接外部 12V 電源 `-`。
- Arduino `GND` 接外部 12V 電源 `-`。
- 三片 ULN2003 的電源負極要共地。

## 安全檢查

- Arduino USB 只負責上傳程式與控制訊號。
- 馬達電源由外部 12V 電源供應。
- 改接線前先拔掉馬達電源。
- 先只接馬達 1，測試成功後再接馬達 2 和馬達 3。
