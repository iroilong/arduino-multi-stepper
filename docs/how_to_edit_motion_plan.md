# 如何修改接線與馬達動作

一般使用者只需要修改 `Stepper3Motors/motion_plan.h`。這個檔案同時包含硬體 pin 對接與馬達動作。

## 使用者設定區 1：硬體接線

打開 `motion_plan.h` 後，先確認這段標題：

```cpp
// 使用者設定區 1：硬體接線
```

這裡記錄每片 ULN2003 的 `IN1`、`IN2`、`IN3`、`IN4` 對應到 Arduino Mega 2560 哪些 pin。若實際接線沒有改，這一區不用動。

## 使用者設定區 2：馬達動作

接著找到這段標題：

```cpp
// 使用者設定區 2：馬達動作
```

請只修改下面三個清單：

- `MOTOR_1_PLAN`
- `MOTOR_2_PLAN`
- `MOTOR_3_PLAN`

## 動作格式

```cpp
PAUSE_SECONDS(3),
MOVE_DEGREES(45, 10),
MOVE_DEGREES(-45, 10),
```

| 格式 | 意思 |
| --- | --- |
| `PAUSE_SECONDS(3),` | 停 3 秒 |
| `MOVE_DEGREES(45, 10),` | 正轉 45 度，約 10 秒完成 |
| `MOVE_DEGREES(-45, 10),` | 反轉 45 度，約 10 秒完成 |

## 注意事項

- 每一行最後都要有逗號。
- 正角度和負角度代表相反方向。
- 如果實際方向相反，把角度正負號對調即可。
- 修改完要重新上傳 Arduino 程式。
- 上傳完成後，Arduino 一上電就會自動開始執行 `motion_plan.h` 裡的動作。
- 若改完無法編譯，先檢查是否少了逗號或括號。
