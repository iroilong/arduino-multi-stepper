使用說明：三顆步進馬達控制

本文件給不會寫程式的使用者使用，目標是說明：

1. 硬體要怎麼接線。
2. 軟體要改哪個檔案來調整馬達行為。
3. 修改後如何用 Arduino IDE 燒錄。

1. 硬體接線

1.1 使用的硬體

- 控制板：Arduino Mega 2560
- 馬達：28BYJ-48 12V DC 步進馬達，共 3 顆
- 馬達驅動板：ULN2003，共 3 片
- 馬達電源：外部 12V 電源

1.2 馬達驅動板訊號線

每片 ULN2003 驅動板上會有 IN1、IN2、IN3、IN4。

請照下表接到 Arduino Mega 2560：

馬達 | ULN2003 IN1 | ULN2003 IN2 | ULN2003 IN3 | ULN2003 IN4
馬達 1 | D22 | D24 | D26 | D28
馬達 2 | D30 | D32 | D34 | D36
馬達 3 | D38 | D40 | D42 | D44

1.3 馬達接到驅動板

- 每顆 28BYJ-48 馬達的白色接頭，直接插到自己的 ULN2003 驅動板白色插座。
- 馬達 1 對應第一片 ULN2003。
- 馬達 2 對應第二片 ULN2003。
- 馬達 3 對應第三片 ULN2003。

1.4 電源接法

Arduino Mega 2560 本身可以用以下其中一種方式供電：

- USB 線供電。
- Arduino 的 DC 電源孔接 12V 供電。

馬達電源請另外接到 ULN2003 驅動板：

- ULN2003 + 接外部 12V 電源正極。
- ULN2003 - 接外部 12V 電源負極。
- Arduino GND 要和外部 12V 電源負極接在一起。

注意：不要用 Arduino 的 5V 腳供應 12V 馬達。

1.5 開機狀態

- 程式燒錄完成後，Arduino 一上電就會自動開始執行馬達動作。
- 板上 L LED，也就是 PB7/D13，會持續閃爍。
- 如果 L LED 有閃，表示 MCU 還在執行程式。

2. 軟體：修改馬達行為

如果要改馬達動作，只需要修改這個檔案：

motion_plan.h

請打開 motion_plan.h，找到：

// 使用者設定區：在這裡調整三顆馬達的動作

一般使用者只改這一區即可。

2.1 可用動作格式

PAUSE_SECONDS(秒數),
MOVE_DEGREES(角度, 秒數),

意思如下：

寫法 | 意思
PAUSE_SECONDS(3), | 停 3 秒
MOVE_DEGREES(45, 10), | 正轉 45 度，約 10 秒完成
MOVE_DEGREES(-45, 10), | 反轉 45 度，約 10 秒完成

注意：每一行最後都要有逗號。

2.2 簡單範例

假設要讓馬達 1 做這個動作：

1. 停 3 秒。
2. 正轉 45 度，花 10 秒。
3. 停 3 秒。
4. 反轉 45 度，花 10 秒。

就把 MOTOR_1_PLAN 寫成：

const MotionStep MOTOR_1_PLAN[] = {
  PAUSE_SECONDS(3),
  MOVE_DEGREES(45, 10),
  PAUSE_SECONDS(3),
  MOVE_DEGREES(-45, 10),
};

2.3 三顆馬達各自設定

在 motion_plan.h 裡會看到三個區塊：

const MotionStep MOTOR_1_PLAN[] = {
  // 馬達 1 的動作寫在這裡
};

const MotionStep MOTOR_2_PLAN[] = {
  // 馬達 2 的動作寫在這裡
};

const MotionStep MOTOR_3_PLAN[] = {
  // 馬達 3 的動作寫在這裡
};

每顆馬達可以有不同角度、不同速度、不同停頓時間。

2.4 常見錯誤

- 忘記逗號：每一行動作後面都要有 ,。
- 括號打錯：MOVE_DEGREES(45, 10), 左右括號要成對。
- 方向相反：把 45 改成 -45，或把 -45 改成 45。
- 速度太快不動：把第二個數字加大，例如 MOVE_DEGREES(45, 20),。

3. 用 Arduino IDE 燒錄

1. 用 Arduino IDE 開啟 Stepper3Motors.ino。
2. 接上 Arduino Mega 2560 的 USB 線。
3. 選擇板子：Tools → Board → Arduino AVR Boards → Arduino Mega or Mega 2560。
4. 選擇處理器：Tools → Processor → ATmega2560 (Mega 2560)。
5. 選擇連接埠：Tools → Port → 選 Arduino Mega 2560 對應的 COM。
6. 按 Arduino IDE 左上角的 Upload 按鈕。
7. 等下方訊息顯示上傳完成。
8. 上傳完成後，Arduino 會重新啟動，馬達動作會自動開始。

4. 如果要看狀態訊息

1. Arduino 用 USB 接到電腦。
2. 在 Arduino IDE 打開 Serial Monitor。
3. Baud rate 選 115200。
4. 可以輸入：

指令 | 功能
? | 顯示說明
r | 重新開始三顆馬達動作
s | 停止並釋放三顆馬達

5. 安全提醒

- 改接線前，先關掉外部 12V 馬達電源。
- 第一次測試時，建議只接馬達 1。
- 馬達正常後，再接馬達 2 和馬達 3。
- 如果馬達只震動不轉，先關電，再檢查 IN1-IN4 順序與馬達接頭。
